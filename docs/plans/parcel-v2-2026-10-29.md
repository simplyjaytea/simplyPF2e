## Decisions

1. **Coin UUIDs have one owner.** `COIN_UUIDS` (full UUIDs, in `scripts/loot-actor.mjs`, where the drift check can see them) is the only table. `coinEntry(denomination)` derives the `{ packId, _id }` lookup that `builder.mjs` passes to `getDocument`. `builder.mjs` no longer holds bare ids. `loot-actor.mjs` was chosen because it is a leaf module (it imports only `text.mjs` and `reskin-policy.mjs`), so the import adds no cycle.
2. **Currency split is a module convention.** The copper total is split into whole coins, largest first: `pp = floor(cp / 1000)`, then `gp`, `sp`, `cp` from the remainder. This follows pf2e's rates, not its display rule (see the `normalized` quote). Table amounts are whole gold pieces, so the split yields pp and gp only: 40 gp is 4 pp, 175 gp is 17 pp and 5 gp, and 320 gp is 32 pp. A fraction such as 0.37 gp would land in sp and cp. Any amount finer than 1 cp throws.
3. **All-or-nothing currency.** Each denomination is cloned from its pinned UUID. If any coin fails to load, the whole currency is dropped with the existing `CurrencyDrop` warning, so the loot actor never holds a partial total.
4. **Dropped ids are shown only for the two drops that `selectParcelSpells` makes:** an unknown slot id and an unknown spell id. The AI's string is capped at 60 characters, passed as data, and printed with `{{this}}`, so the template escapes it. Duplicate-slot and rank-above drops keep their fixed text, because they come from `assignParcelPicks`, which has no id to show.
5. **Merchant is opt-in.** The `lootSheetType` control sits in the same `showContainer` block as the loot-actor name, so it is visible only when the gate is on and a loot actor is the destination (for a parcel, always). `buildLootActorSource` defaults to `"Loot"` and refuses any other value, including `null`. With the gate closed, `#readForm` always returns `"Loot"`.

## Decisions that need the user

- **Pp threshold.** Greedy pp means a level-1 parcel with 40 gp shows "4 pp". If you prefer gp for small parcels, a threshold (for example, pp only at 100 gp and up) is a one-line change in `splitCurrencyGp`.
- **GM Core's currency text** was not fetched in this session. The rates are pf2e's and the split is the module's convention. Confirm that is the rule you want.
