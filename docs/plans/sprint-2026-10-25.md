## WP1 — Static integrity check in the gate

**Why.** `node --check` only parses. A wrong relative import path, a missing named export, a mistyped template path, or a missing `SIMPLYPF2E.*` localization key passes CI today and breaks the module at load or render time in Foundry. C12 proved this check is feasible with a throwaway script; make it permanent.

**Target.** New `tools/check-integrity.mjs`; one call added in `tools/check.mjs`; new `tests/check-integrity.test.mjs`; `README.md` "For maintainers" paragraph that describes the gate (lines near "The command syntax-checks every script, test and tooling module").

**Change.** A dependency-free Node script that fails (exit 1, listing every problem) when:

1. A relative `import ... from "./x.mjs"` / `import("./x.mjs")` / `export ... from "./x.mjs"` in `scripts/**/*.mjs` or `tests/**/*.mjs` does not resolve to an existing file.
2. A named import `{ a, b as c }` names an export the target module does not declare. Recognize `export function|async function|const|let|class NAME`, `export { a, b as c }`, and `export { x } from`. Namespace imports (`* as ns`) and side-effect imports are skipped.
3. A template path string in `scripts/**` of the form `modules/${MODULE_ID}/templates/<name>.hbs` or `templates/<name>.hbs` does not exist, or a `{{> partial-name}}` used in `templates/**/*.hbs` is not registered in `scripts/simplypf2e.mjs`'s `loadTemplates` map.
4. A literal localization key `SIMPLYPF2E.A.B.C` used in `scripts/**` (inside `localize(`, `format(`, string literals) or in `templates/**/*.hbs` (`{{localize "..."}}`) is missing from `lang/en.json`. For interpolated keys (`SIMPLYPF2E.Skills.Rank${row.rank}`, `SIMPLYPF2E.CreatureTools.Adjust.${value}`), check only that the static prefix before `${` resolves to an object (or, when the prefix ends mid-segment such as `Rank`, that at least one key with that segment prefix exists under the parent).

Unused `lang/en.json` keys are **reported as a warning count**, never a failure (a separate backlog item owns their removal).

Wire it into `tools/check.mjs` immediately after the syntax pass and before the regressions, printing one summary line on success (`Integrity passed: N imports, M exports, T templates, L localization keys; U unused keys`).

**Constraints.** No new dependencies. Regex-based scanning is acceptable, but every pattern must be exercised by the test. If the checker finds a real defect in the current tree, report it in the worker report **and** fix it only if the fix is a one-line localization key or path correction that cannot change behavior when correct; otherwise leave the defect, add it to the report, and make the checker still fail (the coordinator decides). Do not whitelist to make the check green.

**Ownership.** `tools/check-integrity.mjs` (new), `tools/check.mjs` (one call), `tests/check-integrity.test.mjs` (new; build a temporary fixture tree under `os.tmpdir()` with one broken import, one bad named export, one missing template, one missing key, one interpolated key; assert the checker reports each and exits non-zero, and that a clean fixture exits 0), the one README paragraph. Nothing else.

**Observable acceptance.**

- `node tools/check-integrity.mjs` exits 0 on the current tree, or exits 1 with a list the report reproduces verbatim.
- `node tools/check.mjs` tail shows the new Integrity line and `Regressions passed: 110 files` (109 + the new test).
- A deliberately mistyped import in a scratch copy is caught (show the command and output in the report).
- `scripts/generator-app.mjs`'s `SIMPLYPF2E.Skills.Rank${row.rank}` is **not** reported as missing.
