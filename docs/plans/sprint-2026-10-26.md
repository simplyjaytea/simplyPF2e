## WP1 — Dead code and localization sweep (backlog 1)

**Why.** `check-integrity.mjs` reports 16 unused `lang/en.json` keys; C12 §3.5 flagged exports with no production consumer (`findFundamentalRune`, `availableEffectKinds`, others). Dead surface misleads reviewers and bloats the shipped archive.

**Change.** Remove lang keys with no static or prefix consumer in `scripts/` or `templates/`; keep anything a test asserts. For exports with zero importers in `scripts/`: keep if a test imports it (report it), otherwise drop the `export` or delete the function. Removals only; no behavior change; no reformatting.

**Ownership.** `lang/en.json`, `scripts/*.mjs` (removals), optionally a list flag in `tools/check-integrity.mjs`.

**Acceptance.** Gate green; unused-key count in the Integrity line drops to the number of test-protected keys (ideally 0); report tables list every removal with grep evidence.

## WP2 — Relative Markdown link check in the gate (backlog 2)

**Why.** The 2026-10-25 docs reorganization relinked 88 links by hand; nothing stops them rotting.

**Change.** New dependency-free `tools/check-links.mjs` (relative links and images in root, `docs/**`, `.github/**` Markdown; file existence; GitHub-style heading anchors; one `file:line: broken link -> target` per failure), wired into `tools/check.mjs` after the integrity check, with `tests/check-links.test.mjs` over a temp fixture tree. Minimal in-place fixes for any real broken link found.

**Ownership.** `tools/check-links.mjs` (new), `tools/check.mjs` (wiring), `tests/check-links.test.mjs` (new), link-target corrections in `*.md`.

**Acceptance.** `Links passed: N links in M files` on the real tree; the fixture test proves both failure modes; gate green.

## WP3 — Opt-in pf2e catalog drift check

**Why.** pf2e schema and content drift is the most repeated bug source in the project's history (PLAYBOOK §3 invariant 3), and every merge auto-publishes. The module hard-codes pack ids (`DEFAULT_PACKS`), `Compendium.pf2e.*` UUIDs, dedication and feat names (`pc-multiclass.mjs`), class profiles (`pc-tables.mjs`), and real-JSON fixtures. Nothing checks them against upstream.

**Change.** New `tools/check-pf2e-drift.mjs [--ref <ref>] [--json]`: derives pack-id to directory mapping from the pf2e `system.json` at the ref; verifies pack ids, UUID ids, catalog names (slug file exists, `name` and publication match), and reports fixture drift as warnings. Network-using, deliberately **not** in `tools/check.mjs`. Pure helpers exported and unit-tested offline in `tests/check-pf2e-drift.test.mjs`. One three-sentence "Drift check" paragraph in PLAYBOOK §7.

**Ownership.** `tools/check-pf2e-drift.mjs` (new), `tests/check-pf2e-drift.test.mjs` (new), the PLAYBOOK §7 paragraph.

**Acceptance.** Tool runs to completion on `master` and `pf2e-8.5.0` with full output in the report; any FAIL is reported, not patched; gate green.
