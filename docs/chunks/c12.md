### 3.3 Fix: unstyled PC editor classes (C06)

`templates/generator.hbs` uses `spf-warning` (alert text and blockers), `spf-pc-edit-row` (control rows), and `spf-pc-editor`. No CSS rule existed for `.spf-warning` or `.spf-pc-edit-row`, so editor errors rendered as plain text and rows had no layout. Added two rules after `.spf-field-note` in `styles/simplypf2e.css`, using existing tokens (`--spf-warning`, `--spf-space-*`). `role="alert"` and live-region behavior are unchanged. Visual appearance is not verified natively.
