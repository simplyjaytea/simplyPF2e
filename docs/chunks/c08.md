# C08: ordinary multiclass, noncaster catalog

## Scope
- Ordinary multiclass dedications and archetype feats for the noncaster catalog, behind the default-off world setting `multiclassArchetypes`. With the setting off, feat resolution and PC editing are unchanged.
- Catalog names are PF2e 8.5.0 source data (see C07 design).
- Lock rules live in `scripts/pc-multiclass.mjs`:
  - A dedication cannot be the PC's own class.
  - A dedication needs no other package in progress, or two more feats taken from the current package.
  - A package feat needs its dedication held, plus any named feat prerequisite.
  - Blocked picks are not counted as held, so their dependents are blocked too.
- Enforced in `resolveFeatPicks` (when `className` is passed), in `applyFeatEdit` (refuses the whole resulting order with `PC_EDIT_MULTICLASS`), and in `remapFeats` (drops blocked picks and reports them).
- `getFeatCandidates` accepts an optional `limit`, so the catalog is not truncated by the 16-candidate sampler.

## Catalog
- Fighter: Fighter Dedication; Basic Maneuver, Reactive Striker.
- Investigator: Investigator Dedication; Basic Deduction, Investigator's Stratagem, Keen Recollection.
- Barbarian: Barbarian Dedication; Basic Fury, Instinct Ability, Advanced Fury (requires Basic Fury).
- Monk: Monk Dedication; Monk Moves, Monk's Flurry.
- Ranger: Ranger Dedication only.

## Exclusions (reported, not silent)
- Rogue: excluded as a whole. Its ChoiceSets query the compendium and fail open to the native prompt, so they cannot be restricted to noncaster feats.
- Basic Trickery, Basic Kata, Basic Hunter's Trick: ChoiceSet queries include caster-only class feats. Their dependents are excluded too.
- Advanced Maneuver, Advanced Deduction: grant an extra class feat with no slot to place it in.
- Feats whose prerequisites need class HP or expert rank cannot be proven by the staged evaluator: Resiliency feats, Diverse Weapon Expert, both Master Spotters, Juggernaut's Fortitude, Perfection's Path. The full list is `MULTICLASS_UNAVAILABLE`.
- Dedication prerequisite text (ability scores) is descriptive and not enforced.
- The Resiliency HP cap is not implemented.

## Unverified
- Choice-bearing ChoiceSets (Basic Maneuver, Basic Deduction, Instinct Ability, dedications) rely on the existing native/preselect flow. Not exercised in a live Foundry session.
- Ranger has no feats that pass the filters, so after Ranger Dedication no further package can be taken.

## Gate
- Multiclass remains behind the default-off `multiclassArchetypes` setting. No new native write path was added, so the experimental gate is unaffected.

## Tests
- `scripts/pc-multiclass.test.mjs` covers catalog membership, own-class block, dedication lock, requires-by-name, blocked-not-held, and drop invalidation.
