# C04: Creature tools UI and native elite/weak adapter

## Files
- `scripts/creature-tools.mjs`: reskin flows over the C03 backend (`listReskinSourceCandidates`, `prepareReskinPlan`, `reskinPlanPreview`, `commitReskinPlan`) with the experimental gate; native elite/weak/normal adapter.
- `scripts/creature-tools-app.mjs`: `CreatureToolsApp` (SpfApp) with reskin and adjustment sections.
- `templates/creature-tools.hbs`: app template.
- `scripts/simplypf2e.mjs`: `openCreatureTools` entry, `module.api.openCreatureTools`, gated actor-directory button.
- `lang/en.json`: `SIMPLYPF2E.CreatureTools` group.
- `scripts/creature-tools.test.mjs`: gate, source-immutability, and adapter regressions with fake Foundry globals.

## Decisions
- Reskin reuses the C03 backend; the plan lives only in memory and is committed through `commitReskinPlan`.
- Elite/weak/normal go only through native `actor.applyAdjustment` (`null` for normal). The preview shows from-to and current HP only; no stats are recomputed.
- Every flow entry and every native write re-checks the experimental gate. A revoked gate prevents the create and the rollback.
- Verification reads the native state back; a mismatch restores the prior state and reports `VERIFICATION_FAILED`, or `ROLLBACK_FAILED` if the restore fails.
- Only world NPCs (not tokens, compendium copies, or other types) are adjustable.

## Verification
- `node scripts/creature-tools.test.mjs` (included in `tools/check.mjs`).
- Gate: `node tools/check.mjs` exit code and `git diff --check`, run once at the end.
